# Contributing to The Arena: The Citizen Handbook

Welcome to Route 66. The highway is at Mile 0, and the road ahead is deliberately unfinished.

In this project, you are not just a code contributor—you are a **Citizen of the Outpost**.

---

## 🏛️ Citizen Roles

When contributing, you can choose one of the core archetypes or propose a new one:

- **The Explorer (Recon & APIs):** Connects external data streams, APIs, feeds, or local note folders into the daemon.
- **The Challenger (Audit & Security):** Writes unit tests, stress-tests agent logic, hunts edge cases, and hardens the architecture.
- **The Builder (Godot & Shaders):** Builds 3D low-poly meshes, shaders (flickering neon, heat haze, sand drifts), and visual mechanics in Godot 4.
- **The Organizer (Lore & Systems):** Designs data structures, archives milestone lore, optimizes JSON/SQLite storage, and crafts community documentation.
- **The Inventor (Emergence):** Experiments with cellular automata, game-of-life mechanics, and novel generative systems.

---

## 🚀 How to Play / Contribute via GitHub

1. **Fork the Repository:** Create your own branch of the Route 66 frontier.
2. **Launch the Outpost:**
   ```bash
   python arena_runner.py
   ```
   Open Godot 4, import `project.godot`, and press **F5**.
3. **Pick a Bounty (Issue):** Check out the open issues marked `Good First Expedition` or `Roadblock`.
4. **Submit a Pull Request:**
   - Summarize: *What was attempted? What was built? What was learned?*
   - Once merged, your work is officially canonized in the central town's history.

*Creed: Dream. Build. Try. Enjoy.*
